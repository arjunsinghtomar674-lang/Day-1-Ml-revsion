# Day 01 — NumPy Revision

This is **Day 1 of my Machine Learning revision journey**, focused on revising NumPy from the basics to practical operations used in Machine Learning.

The goal is not just to learn NumPy syntax, but to become comfortable with **handling and manipulating numerical data** before moving to Pandas and EDA.

## 📌 Topics Covered

* Introduction to NumPy
* NumPy Arrays
* `shape`, `ndim`, and `dtype`
* Creating Arrays

  * `np.array()`
  * `np.zeros()`
  * `np.ones()`
  * `np.arange()`
  * `np.linspace()`
  * `np.random.rand()`
  * `np.random.randint()`
* Array Indexing
* Array Slicing
* 1D and 2D Arrays
* Mathematical Operations
* Statistical Operations

  * `mean()`
  * `median()`
  * `min()`
  * `max()`
  * `sum()`
  * `std()`
  * `var()`
* Reshaping Arrays

  * `reshape()`
  * `flatten()`
* Understanding `axis=0` and `axis=1`
* Boolean Masking
* Copy vs View
* Sorting Arrays
* `unique()`
* `concatenate()`
* `argmax()` and `argmin()`

## 🧠 Practical Questions

As part of the revision, I practiced:

1. Finding the shape of an array
